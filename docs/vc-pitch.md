# Libraries.dev — VC Pitch (10 slides)

## 1. Title
**Libraries.dev**
Craft, as infrastructure.
In a world where anyone can build software, we make yours feel like the top 1%.
Jakub Antalik — founder & designer. 1.4M installs a month.

## 2. Problem — everything looks the same now
- AI agents collapsed the cost of building software. Millions of products ship every month — and they all look and feel identical.
- Agents are trained on the average internet, so they generate the average interface. Same components, same layouts, same dead feel.
- When code is a commodity, **the product that *feels* exceptional wins**. And feel is the one thing you can't prompt into existence.

## 3. The insight
- Taste doesn't scale through people — it scales through packages.
- A hand-tuned effect, encoded as a library, gives every product that installs it the polish of a world-class design engineer.
- We turn craft into a dependency: `npm install` the difference between average and unforgettable.

## 4. Product — the craft layer
- **Five living-interface libraries**: Beam, Orb, Gooey, Metal, Image — glows, liquid motion, AI thinking states, real-time chrome, generative loaders. ~83 KB gzip for all of it.
- **Studio (Pro)**: tune every parameter visually, preview live, export the exact config — your product's feel, not a template's.
- **Agent-native**: shipped as skills agents can invoke — the AI that builds the product installs the polish itself.

## 5. Traction — pulled, not pushed
- **1.41M npm installs last month** (478K last week). Zero marketing spend.
- Orb (thinking-orbs): 858K/month — 97% of its all-time volume in the last 30 days. It's becoming the default "AI is thinking" indicator.
- Beam: 413K/month, steady for a year. Newest library hit 6K/week within weeks of launch.
- The AI building boom isn't our competition — it's our tailwind. More products built = more products that need to stand out.

## 6. Business model
- **Free**: MIT libraries on npm — the growth engine and the standard-setter.
- **Pro** — $9/mo · $90/yr · $149 lifetime (team $39/$390/$499): the Studio, every Pro preset and variant, all future libraries, commercial license.
- Playbook already proven live on transitions.dev (sister product): payments, licensing, Pro platform — built and running.

## 7. Why now
- The gap between "built by AI" and "feels designed" has never been wider — and it's widening every month.
- Every AI product needs the same new visual language: thinking states, generation loaders, living surfaces. We define it.
- Agents choose dependencies. Whoever is the default choice of the agents owns the distribution channel of the next decade.

## 8. Moat
- **Taste**: hand-tuned motion, WebGL craft — trained-on-average models can't generate it, marketplaces can't copy the feel.
- **Default status**: 1.4M installs/month makes these the libraries agents already reach for.
- **Cross-platform**: SwiftUI + React Native ports carry each effect beyond the web — almost nobody follows there.

## 9. Roadmap
- Studio v1 + billing backend (api.libraries.dev) — turn 1.4M monthly installers into customers.
- Agent distribution: skills + MCP so every coding agent installs and configures the catalog natively.
- Mobile parity for all five; new libraries quarterly.
- 0.1% of monthly installers → ~1.4K seats ≈ $150K ARR floor. 1% ≈ $1.5M ARR.
