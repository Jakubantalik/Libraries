How to use

  1. 1

    Install

    Every library is a standalone npm package — grab only what you need: npm install border-beam, thinking-orbs, liquid-gooey, metal-fx or img-fx.

  2. 2

    Drop it in

    Import the component and wrap your UI — React 18+, zero runtime dependencies, light and dark mode built in. Works from Cursor, Claude Code and Codex out of the box.

  3. 3

    Make it yours

    Tune the effect in each library’s playground, or go deeper in the Studio with Pro and export the exact configuration as props.
