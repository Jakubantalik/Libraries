Features

  • Extra variants and types

    States, sizes and effect types the detail pages hold back: the full set of orb states, every beam family, all four gooey effects.

  • The full parameter surface

    Every knob the libraries expose: beam duration, brightness and hue range; gooey spring physics per effect; metal ring and shader scale; image pixel grids and palettes.

  • Physics-level tuning on Gooey

    Morph, Move, Bend and Melt each get their own panel — springiness, wobble, stretch, trail, melt reach and marbling, all live.

  • Live preview, real package

    The stage renders the same published npm packages your app installs, so what you tune is exactly what ships.

  • Code export

    A live JSX snippet tracks your settings, listing only non-default props. Copy it with one click.

  • Built for agent workflows

    Exports drop cleanly into Cursor, Claude Code or Codex sessions — tune by hand, let the agent do the wiring.
