How to use

Every library ships as a prompt. Copy it, paste it into your coding agent, and make it yours. Three steps, no setup.

  1. 1

    Copy the prompt

    Every library page has a Copy prompt button: the install line, usage and full prop vocabulary in one paste, so your agent gets the whole library. 

    Border beam is an animated rainbow glow that rides any border.
Install border-beam from npm, wrap the element, then tune
size, colorVariant, strength, duration and brightness…
  2. 2

    Paste it in your agent

    Drop the prompt into Claude Code, Cursor or Codex. The agent installs the package and wires it into your app, matched to your theme. React 18+, SSR safe. 

    $ claude
› [Pasted text #1 +42 lines]

✓ npm install border-beam
✓ components/ui/upgrade-card.tsx
✓ wrapped <Card> in <BorderBeam>, matched to your theme
  3. 3

    Make it yours

    Every library page has a playground for its main knobs. Open the Studio with Pro for the full parameter surface, tune the component live, and copy the configuration as props. 

    <BorderBeam size="line" colorVariant="ocean" duration={3.2} brightness={1.6} />
